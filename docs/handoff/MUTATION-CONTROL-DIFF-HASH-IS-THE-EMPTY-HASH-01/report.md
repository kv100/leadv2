## Громкая половина посылки — ложна, и на большем масштабе, чем при закрытии

Перепись **всех** артефактов контроля мутаций в обоих репозиториях, а не восьми:

```
artifacts: 87
distinct diff_hash: 81
diff_hash == sha256("") : 0
```

Ни один артефакт не несёт пустой хеш как `diff_hash`. Мутация применялась, сюита краснела —
восемьдесят один раз по-разному. Строка ряда «diff hash is the empty hash» неверна как утверждение
о продукте.

## Тихая половина — верна, и вот её сегодняшний размер

```
carry lane_diff_hash:      84 / 87   (3 старше самого поля)
lane_diff_hash == sha256(""):  8
```

Восемь артефактов несут **пустую идентичность лейна**: они доказывают «эта сюита краснеет от этой
мутации» и не доказывают «она покраснела на ЭТОЙ работе» — ровно та потеря тождества, которую ряд
и починил. Их пять владельцев:

```
2  leadv2/docs/handoff/WRITESET-CAROUSEL-01
2  leadv2/docs/handoff/PHASE-GATE-NAMES-EVERYTHING-AT-ONCE-01
2  leadv2/docs/handoff/ARBITER-REMEMBERS-FAILURES-01
1  leadv2/docs/handoff/PHASE-GATE-DEFAULT-CLASS-ESCAPES-IT-01
1  leadv2/docs/handoff/DARK-SUITES-UNREACHABLE-BY-RUNNER-01
```

Все восемь — историческая форма, и сегодня она **отвергается**: случай сюиты «the gate refuses an
empty lane identity even when its own expected value is equally empty, and still accepts a real one»
зелёный, то есть гейт не принимает такой артефакт даже когда его собственное ожидаемое значение
тоже пусто (случай, в котором сравнение выродилось бы в тождество). Чего я **не** делала: не
переоткрывала эти пять закрытых рядов — я утверждаю только форму их артефактов, а не качество их
работы.
