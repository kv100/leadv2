## Почему слито ноль

Твоё правило: сливать только единицы, где `--diff-filter=D` пуст и `--stat` читается как вклад.
Пересечение множеств даёт пустоту:

- 38 из 49 конфликтуют — чистого слияния нет ни у одной;
- из 11 чисто сливаемых **десять несут только docs** (`wip(…): lane work preserved`, журналы);
- одиннадцатая — `m8dod`:

```
$ git merge-tree --write-tree main worktree-m8dod   # rc=0
$ git diff --diff-filter=D --name-only main fd9cc7a3   # пусто
$ git diff --stat main fd9cc7a3
 MISSION.md | 62 ++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
```

Формально проходит оба условия. По существу — это бриф линии M-8 («You are a plain software
engineer…»), которого на main нет и быть не должно: слияние положит инструкцию для воркера в
корень репозитория. Чистый rc — разрешение посмотреть, а не разрешение слить; посмотрел и не слил.

Ветки `908164a1`, `c5daf449`, `b7bcf98a` конфликтуют по одному-двум файлам (`hooks.json`,
`leadv2-broad-status.sh`, диспатчеры) — но все три вытеснены, так что разрешать конфликт незачем.
