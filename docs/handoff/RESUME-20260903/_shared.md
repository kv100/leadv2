# Shared constraints for every resumed lane (2026-09-03)

Твоя линия была убита падением редактора, не тобой и не проверкой. Работа цела:
коммиты и несохранённые файлы лежат в твоём worktree. Продолжай с того места.

ПЕРВЫМ ДЕЛОМ: прочитай `docs/handoff/<TASK-ID>/` в СВОЁМ worktree (там твой бриф и
твои записи, если ты успел их сделать), затем `git log --oneline main...HEAD` и
`git status`. Восстанови контекст оттуда, а не из этого файла.

ОБЩИЕ ПРАВИЛА (нарушение = линия не принимается):
- Негативный контроль на каждое утверждение: мутация ВНУТРЬ тела функции (не на
  верхний уровень файла — вставка на верхний уровень красит всё по неверной причине
  и читается как проход), сюита красная, откат, зелёная. Доказательство — пара
  baseline_rc/mutated_rc и красная строка, НЕ diff_hash.
- Сюиту зарегистрировать в EXTRA_SUITE_MAP в tests/run-all.sh и доказать через
  `--scope changed`, что раннер её ВЫБИРАЕТ. Незарегистрированная сюита сгниёт молча:
  из 23 сюит, на которые опирался план, раннер видит 9.
- Перед сдачей: `git diff --diff-filter=D --name-only main...HEAD` (ТРИ точки —
  две точки показывают чужие коммиты в main как твои удаления). Что удаляется по
  ошибке — вернуть из main.
- Свои заметки и находки пиши в `docs/handoff/<TASK-ID>/` В СВОЁМ WORKTREE и коммить.
  Не в /tmp: /tmp умирает вместе с сессией, и именно так сегодня потерялись брифы.
- Коммить часто, маленькими шагами. Незакоммиченная работа — единственное, что
  падение может отнять.
