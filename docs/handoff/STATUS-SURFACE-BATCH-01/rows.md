## STATUSLINE-FLICKER-PARTIAL-CACHE-01
STATUSLINE-FLICKER-PARTIAL-CACHE-01 (P1, founder-observed 2026-07-30: 'постоянно вижу что статуслайн скачет из статуса в статус, то часть убралась, то добавилась'): the status line never computes synchronously. Per its own header (plugins/leadv2/scripts/leadv2-lane-status-line.sh ~38-52), the main path does exactly one of two instant things — cat a cached last-known-good line (~114-115), or, with no cache, print a minimal static line built from bash-builtin regex only — and then fires ONE detached, lockfile-throttled background refresher (throttle LEADV2_STATUSLINE_REFRESH_MIN_INTERVAL_S) that runs the real work (two jq reads, the wrapped user command, git-branch fallback, lane calc) and rewrites the cache FOR THE NEXT RENDER. Consequences the founder is actually seeing: (1) every line shown is the PREVIOUS refresh's result, so the line is always at least one refresh interval stale; (2) when one component of a refresh fails or times out — most likely the wrapped user command under its timeout 2 — that segment is missing from the line that gets cached, so it vanishes from the display and reappears on a later successful refresh; (3) a wholly failed refresh leaves the old cache in place, so values freeze and then jump. The visible symptom is segments appearing and disappearing between renders, which reads as an unreliable display even when the underlying data is fine. Required: a refresh must be all-or-nothing — never cache a partially-built line; if a component fails, keep the previous value for THAT component rather than dropping the segment, and never let a partial result overwrite a complete cached one. The line must be stable between renders: no segment may appear or disappear while the underlying lane set is unchanged. Distinct from STATUSLINE-SHOWS-LANES-QUESTIONMARK-01 (that one is the count and the fallback); this one is cache/refresh integrity. Verify by rendering repeatedly over several minutes with a fixed lane set and diffing consecutive lines — they must differ only where reality differed.
