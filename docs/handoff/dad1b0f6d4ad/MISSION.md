# FABLE-CANNOT-TAKE-ANY-NON-PRODUCT-LANE-01

fable объявлена в матрице как plan/audit/review и ни один из этих kind не входит в список непродуктовых, поэтому любая её линия обязана пройти архитектурный предпроход — и для диагностической миссии без правок кода он не может выдать дизайн в принципе. Замерено 2026-09-14 на живом диспатчере: --kind audit --pin-arm fable доходит до architect_prepass task=21d40adf status=parked reason=no_design_after_2_attempts last_reason=timeout worker_launched=0, rc=3, линия ПРИПАРКОВАНА и не отправлена; --kind diagnosis --pin-arm fable отвергается раньше как reason=requested_arm_incapable (diagnosis отображается в code, которого у fable нет); --kind review --pin-arm fable резолвится как arm=fable model=fable reason=explicit_requested_capable, но review так же не входит в список непродуктовых и упрётся в тот же предпроход. Список зашит литералом: LEADV2_NON_PRODUCT_KINDS="plugin|tooling|tool|docs|documentation|diagnosis|diagnostic|investigation" (leadv2-dispatch-code.sh:4329), присваивание без :- , то есть переменной окружения его НЕ переопределить, хотя сообщение об ошибке на :9093 предлагает ровно это как средство (remedy=--kind:${LEADV2_NON_PRODUCT_KINDS}). Получается пересечение пустое: множество kind, которые берёт fable, и множество kind, не требующих предпрохода, не пересекаются — fable сегодня структурно не может взять ни одну исследовательскую линию, чей результат отчёт, а не диск. Предпроход тут не флак, а неприменимость: он требует LANE_WRITES и блок приёмки, а у диагностической миссии правок кода нет по замыслу. Чинить надо не обходом конкретной линии, а одним из двух: либо сделать список непродуктовых kind переопределяемым и тогда согласовать его с сообщением об ошибке, которое уже обещает это средство, либо дать предпроходу законный ответ вида "дизайна нет, потому что линия ничего не пишет" вместо таймаута. Обязательный негативный контроль на любую починку: настоящая продуктовая линия с правками кода по-прежнему обязана получить предпроход и припарковаться без дизайна — иначе починка снимает гейт, а не делает его применимым.

## Method — binding

- Name the surface of every count; report the command that produced each number.
- Run the negative control this row names. A rule you cannot demonstrate refusing is not a rule.
- Register any new suite so `tests/run-all.sh --scope changed` SELECTS it.
- Do NOT renumber `capability` (founder ruling 2026-09-14) and do NOT write into
  `router_v2.cost` (that thread is closed on measured evidence).
