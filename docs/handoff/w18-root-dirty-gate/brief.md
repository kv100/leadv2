# W18-ROOT-DIRTY-GATE-01 — гейт грязного дерева срабатывает всегда (§1.8, задача 1)

Ряд `9cf1390c197a`. Полная постановка: `PRE-WAVES-PLAN.md` §1.8 в persona-engine.

## Что сломано, проверено по коду 2026-09-10

`plugins/leadv2/scripts/leadv2-dispatch-product-close.sh:4059`:

```bash
elif [[ -n "$(git -C "${ROOT}" status --porcelain 2>/dev/null)" ]]; then
  # Shared tree has foreign uncommitted work right now -- merging here risks another
  # session's in-flight edits. Never force past this: fail toward pass_unlanded.
  _dl_note pass_unlanded root_dirty ...
```

Проверка идёт по **всему корню**. В `~/Projects/leadv2` постоянно **125** грязных записей
(в основном untracked), пересечения с файлами линии нет. Значит ветка срабатывает **всегда, а не
иногда**, и сработает на каждой будущей линии.

Замер за период с 2026-09-06: **14 из 18** `pass_unlanded` несут `cause=root_dirty`. Работа
сделана, ревью пройдено, слияния нет — доделывает лид руками.

## Намерение комментария верное, проверка несоразмерна

Опасение «чужая сессия правит дерево прямо сейчас» законно, и снимать его нельзя. Но:

- **untracked файл не может быть затёрт слиянием**, если слияние само его не создаёт;
- изменённый tracked файл опасен только тогда, когда он **входит в файловый набор слияния**.

Починка: сузить проверку до пересечения с merged-tree набором линии —
`tracked-modified ∪ (untracked ∩ файловый набор слияния)`. Пусто — сливаем; непусто — отказ
с прежней громкостью и перечислением конкретных путей.

## Правило
**Переиспользовать существующее.** В main уже лёг `leadv2-land.sh` с функцией
`land_in_write_set` и проверкой merged-tree против write set линии (коммит `4aad82dd`,
`W-LEAD-LAST-MILE-01`). Тот же инструмент применить здесь; **второй набор правил не заводить**.
В отчёте назвать, что именно переиспользовано.

Учесть при этом: `leadv2-land.sh:303` тоже читает `git status --porcelain` по всему корню —
проверить, не тот же ли это дефект, и сказать в отчёте.

## Приёмка — обязательный негативный контроль, проверяется лидом
1. Сюита на ОДНОЙ фикстуре: корень грязен файлами, **не** пересекающимися с набором линии, —
   слияние проходит; корень грязен файлом, который **входит** в набор, — отказ с ненулевым
   кодом и строкой, называющей конкретный путь. Разница между случаями только в пересечении.
2. Сюита: untracked файл, которого слияние не создаёт, слияние НЕ блокирует; untracked файл,
   который слияние создаёт, — блокирует.
3. Прогон против настоящего корня с его 125 грязными записями: линия с непересекающимся
   набором обязана приземлиться. Число грязных записей на момент прогона назвать в отчёте.
4. Негативный контроль: вернуть проверку по всему корню ВНУТРЬ тела функции — сюита из п.1
   краснеет на названном тесте.
5. Зелёный и красный прогон целиком в отчёт, плюс артефакт в
   `docs/handoff/w18-root-dirty-gate/mutation-control/`. Лид прогонит мутацию независимо на
   настоящем файле.
